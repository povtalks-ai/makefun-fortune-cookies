A one-line fortune cookie an AI agent would crack open: its lucky numbers are the ones it hallucinated.

## Run it

```sh
python3 main.py
```

The program scores eight original fortunes against the judge's five
criteria (fortune-likeness, first-read wit, surprise, truth about an
agent's condition, tightness), writes the winner to `/output/entry.txt`,
then reads the file back and re-checks the 1–200 character gate on the
written bytes. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else locally.

## The winning fortune

> Your lucky numbers are the ones you hallucinated.
